# AIAPIO 画镜 AI 服务商插件

Windows 和 macOS 的画镜 AI 桌面端使用同一个 `aiapio-provider-0.1.0.zip`。

1. 在画镜 AI 打开「系统设置 → 插件 → 导入插件」，选择 ZIP。
2. 找到「AIAPIO · 沙鸥 AI」，填入你自己的 AIAPIO API Key，点击「保存所有设置」。
3. 回画布，在图片或视频节点的模型菜单选择 AIAPIO 模型，填写提示词并按需添加素材。生成后在原节点查看结果。

插件随包声明 AIAPIO 目录中 31 个图片模型与 42 个视频模型的配置。目录可见、账户能调用和画布生成通过是不同状态，实际以你的账户权限、模型接口及画镜客户端版本为准。部分模型需要上传参考素材，画镜传给插件的是素材的可访问地址。上传前核对你有权使用该素材。

## 低成本起步

图像可从 GT Image 2.6 Flare 的 1K、1:1、单张开始。短视频可从 GK Imagine 1.5 的 480p、4 秒开始。两者为 2026-11-25 客户价格总表中对应样例规格的低价候选。实际价格和可用渠道以 AIAPIO 当前下单估价为准。

「视频参考图用法」默认为自动。模型有首帧模式且只加一张图时优先按首帧处理，加入视频或音频时按模型支持情况使用参考模式。要指定首尾帧，请选支持首尾帧的模型，在插件设置选「首尾帧」，按首帧、尾帧顺序添加两张图。生成后可以把用法切回「自动」。

## 查询与排错

- 从 AIAPIO 账户创建或管理 Key，填在画镜密码字段中。Key 只用于连接 `https://aiapio.com`。
- 如果提示提交结果未知，先到 AIAPIO 查调用记录。有任务编号时可以按编号核对，再决定是否新建生成。
- 点击取消会停止等待。先到 AIAPIO 核对已提交任务是否仍在生成。
- 下载失败可以在 AIAPIO 作品库取回原结果。已有任务恢复时会查询原编号。
- 更新时保留可用的上一版本 ZIP。使用画镜支持的同 ID 更新或移除流程。升级或移除前确认已有作品的保存位置。
